This HTML file contains a simple graphing calculator application. It can evaluate mathematical expressions, as well as graph one or more two-dimensional equations on a dynamically resizable grid.

This graphing calculator was created by utilizing Claude Code AI for my CSCI 713 class.

The open-source project which this application aimed to emulate the functionality of is the Geogebra calculator application. The github link to that project can be found here: https://github.com/geogebra/geogebra
